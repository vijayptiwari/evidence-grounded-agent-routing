# Support

This is an alpha research reference implementation, not a managed service or production support offering.

Use GitHub Issues for reproducible defects, documentation corrections, schema proposals, and benchmark-method questions. Include the project version, Python version, operating system, command, expected behavior, actual behavior, and a synthetic reproducer when applicable.

Security-sensitive reports belong in the private channel described in [SECURITY.md](SECURITY.md), not in a public issue. General implementation questions should not contain private requests, secrets, customer data, or production traces.

Questions about applying the architecture to a specific organization may require policy, security, privacy, legal, or domain review that this project cannot supply.
