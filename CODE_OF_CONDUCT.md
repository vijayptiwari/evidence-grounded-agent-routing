# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Project spaces should be welcoming, respectful, and free from harassment. Constructive disagreement about designs, evidence, limitations, and research claims is welcome; personal attacks, intimidation, discriminatory conduct, unwanted sexual attention, deliberate disruption, and disclosure of another person’s private information are not.

The code applies to repository issues, pull requests, reviews, discussions, commits, and other official project channels, as well as public conduct by someone explicitly representing the project.

Report unacceptable behavior privately through GitHub’s private vulnerability-reporting channel for this repository. If that channel is unavailable, contact the repository owner privately through the GitHub profile. Do not put a conduct report or another person’s private information in a public issue.

The maintainer will review reports as impartially and confidentially as practicable and may correct, hide, reject, or remove contributions; restrict participation; or apply a temporary or permanent ban in proportion to the behavior and its impact. Retaliation against a reporter or participant in an investigation is itself unacceptable.

The canonical Contributor Covenant text and its community-impact enforcement guidance control if this summary is incomplete.
